## Setup
{% admonition() %}
All below instructions are for mac/linux, I haven't included Windows-specific commands since I can't test them directly and want to avoid sharing broken snippets. 
{% end %}

First set of commands to be run,
```bash
# create directory
mkdir ~/gthmchttr.com/
cd ~/gthmchttr.com/

# initialize a zola SSG project in created folder
zola init .
# bring up webserver for testing
zola serve
```
Check the localhost url emitted by last command (usually [http://localhost:1024](http://localhost:1024)), 
{{ img(src="/202609/blog_no_template_page.png", alt="zola no template page") }}

You should see an error which is zola complaining that a theme as not been configured. So let's go ahead and do that - 
```bash
# initialze a git repository
git init
# add a theme as a submodule
git submodule add https://github.com/gauthamchettiar/zola-yolk.git themes/zola-yolk
```
I am using my own theme called [zola-yolk](https://github.com/gauthamchettiar/zola-yolk) here (same one that this website is using), feel free to use whatever you like from {{elink(text="theme gallery" href="https://www.getzola.org/themes/")}}. Most of the commands below are specific to this theme, if you use a different one make sure to check it's documentation for specific installation instruction.  

Next, copy over the default configuration file to tell Zola to use the theme:
```bash
cat themes/zola-yolk/example_zola.toml > zola.toml
```

Head back to [http://localhost:1024](http://localhost:1024) in your browser, your local site should now render properly!

## Authoring

Before you go ahead and add some content let's fix that title!

Open <u>zola.toml</u> file from your project root, and update below settings -
{{ img(src="/202609/blog_config_change.png", alt="Zola Config Change") }}

- {{ color(text="base_url", color="blue") }} : if you've bought a domain, this is where you need to put it (otherwise leave it blank for now)
- {{ color(text="title", color="blue") }} : the site title displayed in header and browser tab. 
- {{ color(text="description", color="blue") }} : something about your website (used by search engines for SEO) 

{% admonition(color="blue") %}
Do make sure to search <u>zola.toml</u> for "CHANGE ME", there's more stuff to replace - 
{{ img(src="/202609/blog_change_me.png", alt="Blog Change Me") }}
{% end %}

...and add a frontmatter to it -

## Publishing
So we've got it working locally, next it's time to make it public!

```bash
mkdir -p .github/workflows
cp themes/zola-yolk/.github/workflows/deploy.yml .github/workflows/
```

That should copy over deployment config from theme over. Next, time to create a github repo...
{{ img(src="/202609/blog_github.png", alt="Blog Github") }}

... then push your code,
```bash
git add .
git commit -m "post: is it up?"
git remote add origin https://github.com/gauthamchettiar/gthmchttr
git push --set-upstream origin main
```

## Setting up Domain

This happens because zola needs a valid `base_url` in <u>zola.toml</u> to locate static assets like CSS files.  

### Use Github's Default Domain
If you are not yet ready to spend extra to buy a domain, all you have to do is to replace {{ color(text="base_url" color="blue") }} setting in <u>zola.toml</u> with actual url you see on github CI page,
{{ img(src="/202609/blog_github_domain_update.png", alt="Blog Github Domain") }}

Now once you commit and push your changes,
{% border() %}
{{ img(src="/202609/blog_up_github_domain.png", alt="Blog Up Github Domain") }}
{% end %}

### Use Your Custom Domain

If you own a domain, you need to configure four {{color(text="A", color="blue")}} records in your domain manager pointing to Github Pages IP Addresses,

| Type | Name | Content |
| --- | --- | --- |
| A    | @    | 185.199.108.153 |
| A    | @    | 185.199.109.153 |
| A    | @    | 185.199.110.153 |
| A    | @    | 185.199.111.153 |

{{ img(src="/202609/blog_a_record.png", alt="Blog A Record") }}

Replace {{ color(text="base_url" color="blue") }} setting in <u>zola.toml</u> with your custom URL,
{{ img(src="/202609/blog_custom_domain_update.png", alt="Blog Custom Domain") }}

Go back to {{ color(text="Repo > Settings > Pages", color="blue") }} -> Replace "Custom Domain" with your domain, 
{{ img(src="/202609/blog_custom_domain_github.png", alt="Blog Custom Domain Github") }}

And that's it, your site should be live and kickin'!
