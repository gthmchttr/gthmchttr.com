## Prerequisites

- Install [zola](https://www.getzola.org/)
- Install [git](https://git-scm.com/)

## Setup
{% admonition() %}
All below instructions are for mac/linux, I have not included windows specific commands as I won't be able to test them and do not want to include a non-working command.
{% end %}

First set of commands to be run,
```bash
# create directory
mkdir ~/ghthmchttr.com/
cd ~/gthmchttr.com/

# initialize a zola SSG project in created folder
zola init .
# bring up webserver for testing
zola serve
```
Check the localhost url emitted by last command, it should give you something like [http://localhost:1024](http://localhost:1024), 
![zola no template page](/202609/blog_no_template_page.png)

You should see an error which is zola complaining you have not provided it a theme. So let's go ahead and do that - 
```bash
# initialze a git repository
git init
# add a theme as a submodule
git submodule add https://github.com/gauthamchettiar/zola-yolk.git themes/zola-yolk
```
I am using my own theme called [zola-yolk](https://github.com/gauthamchettiar/zola-yolk) here (same one that this website is using), you are free to use whatever you like from {{elink(text="theme gallery" href="https://www.getzola.org/themes/")}}. In which case you'd be changing the git project in submodule command above.

It still wouldn't work as you still have to tell zola where the theme is,

{% admonition(icon="triangle-exclamation", color="pink") %}
Below step is specific to this theme, if you are using a different one make sure to check their theme specific installation instruction. 
{% end %}

```bash
cat themes/zola-yolk/example_zola.toml > zola.toml
```

This would copy over essential settings required for theme to work. Now let's check back [localhost](http://localhost:1024) url - 
![Blog Working Homepage](/202609/blog_working_home.png)
Yay! That's something!

## Authoring

Before you go ahead and add some content let's fix that title!

Open <u>zola.toml</u> file from your project root -
![Zola Config Change](/202609/blog_config_change.png)

Here you should be changing below configs,

- {{ color(text="base_url", color="blue") }} : if you've bought a domain, this is where you need to put it (other leave it blank for now)
- {{ color(text="title", color="blue") }} : this is what shows up on top left as a title
- {{ color(text="description", color="blue") }} : something about your website, useful for search engines

{% admonition(color="blue") %}
Do make sure to search for "CHANGE ME", there's more stuff to replace - 
![Blog Change Me](/202609/blog_change_me.png)
{% end %}

Next, time to add a new post... 
```bash
mkdir content/posts/2026/
touch content/posts/2026/20260923_is_it_up.md
```

...and add a frontmatter to it - 
![Blog Front Matter](/202609/blog_yaml_frontmatter.png)

Your post should be up now!
![Blog After Post](/202609/blog_after_post.png)

## Publishing
So we've got it working locally, next it's time to make it public!

```bash
mkdir -p .github/workflows
cp themes/zola-yolk/.github/workflows/deploy.yml .github/workflows/
```

That should copy over deployment config from theme over. Next, time to create a github repo, then push your code -  

![Blog Github](/202609/blog_github.png)
```bash
git add *
git commit -m "post: is it up?"
git remote add origin https://github.com/gauthamchettiar/gthmchttr
git push --set-upstream origin main
```
